# lap-system-auteco-
# Automatización de Inspecciones

## Descripción

Aplicación web desarrollada para digitalizar y optimizar el proceso de inspecciones operativas, ambientales y de seguridad.

El sistema permite registrar inspecciones, gestionar listas de verificación, documentar hallazgos, realizar seguimiento de acciones y visualizar indicadores de cumplimiento.

---

# Objetivo del Proyecto

Reducir el uso de registros manuales, mejorar la trazabilidad de las inspecciones y facilitar la toma de decisiones mediante información organizada y actualizada.

---

# Funcionalidades Principales


## Registro de Inspecciones

Permite crear nuevas inspecciones ingresando:

- Área evaluada.
- Inspector responsable.
- Fecha.
- Tipo de inspección.
- Hallazgos encontrados.
- Responsable de cierre.
- Fecha compromiso.


---

## Checklist Digital

Incluye evaluación de criterios:

- Orden y limpieza.
- Gestión de residuos.
- Estado de puntos ecológicos.
- Seguridad industrial.
- Condiciones locativas.
- Señalización.


Cada criterio puede ser marcado como:

✔ Cumple

✘ No cumple


---

## Gestión de Hallazgos

Permite registrar:

- Descripción del hallazgo.
- Nivel de prioridad.
- Responsable asignado.
- Fecha compromiso.
- Observaciones.


---

## Seguimiento de Acciones

Control del estado de las acciones:

- Pendiente.
- En proceso.
- Completada.
- Cerrada.


---

## Indicadores

El sistema calcula automáticamente:

- Total de inspecciones.
- Inspecciones completadas.
- Inspecciones pendientes.
- Porcentaje de cumplimiento.
- Barra visual de avance.


---

## Exportación de Información

Permite descargar el registro de inspecciones en formato CSV compatible con Excel.
